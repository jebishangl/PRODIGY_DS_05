# PRODIGY_DS_05 - Traffic Accident Analysis

# Task Objective
To analyze accident data and identify patterns related to time, weather, and location.

# Dataset
US Accidents Dataset

# Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib

# What I Did
- Loaded and cleaned large dataset
- Handled missing values using mean and mode
- Extracted time-based features
- Visualized accidents by time, weather, and severity
- Identified accident hotspots using location data

# Key Insights
- Accidents are more frequent during peak hours
- Weather conditions like fog and rain increase accidents
- Certain locations show higher accident density
- Most accidents fall under moderate severity
